{# ================= 5. Comment lire / limites ================= #}

Comment le système a obtenu ce résultat

  1. Il classe chaque image. Le modèle U-Net range chaque pixel de 10 m dans une des cinq classes : eau, végétation dense, végétation clairsemée, sol nu, sable/dune.
  2. Il résume chaque période. Pour les 3 premières et les 3 dernières images, chaque pixel reçoit l'état qu'il a au moins 2 fois sur 3 : eau, végétation ou surface nue. Cela écarte les erreurs isolées.
  3. Il compare les deux périodes. Un pixel passé de végétation à surface nue est une perte candidate ; l'inverse est un gain. Les changements liés au lac sont mis à part.
  4. Il vérifie avec une deuxième mesure. Le NDVI, calculé directement à partir des images, doit baisser de plus de 0,10 entre les deux périodes. Il ne dépend pas du modèle.
  5. Il écarte les petites taches. Seules les taches d'au moins 0,5 ha (50 pixels) sont retenues, pour ne pas compter le bruit de classement.

Ce qu'il faut garder en tête

  • Le modèle n'est pas parfait : il s'accorde avec les masques de référence dans environ 3 cas sur 4 (exactitude 0,765). Une partie des changements affichés peut être une erreur de classement.
  • Les masques de référence ont été produits automatiquement : il n'y a pas eu de vérification sur le terrain.
  • Les images doivent être de la même saison ; la pluie de chaque année n'est pas prise en compte.
  • Le modèle a été entraîné et évalué autour de Bol ({{ emprise_modele | join(", ") }}) : ailleurs, le résultat est indicatif.
